# Лабораторная работа № 2

Простой калькулятор на Python поддерживает сложение, вычитание, умножение и деление.

## Требования

Нужен Python 3. Выполнять команды следует из корневой папки репозитория.

## Запуск программы

```powershell
python LR2/main.py
```

## Запуск тестов

```powershell
python -m unittest discover -s LR2/tests -p "test_*.py"
```

При попытке деления на ноль функция `divide` возбуждает стандартное исключение `ZeroDivisionError`; этот случай покрыт тестом.
