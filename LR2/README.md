# Лабораторная работа № 2

Простой калькулятор на Python поддерживает сложение, вычитание, умножение,
деление и возведение в степень.

## Версия и документация

Текущая версия — `1.0.0` (см. [VERSION](VERSION)). Изменения перечислены в
[CHANGELOG.md](CHANGELOG.md). HTML-документация модуля `LR2.calculator`
автоматически создаётся workflow `LR2 Documentation` и прикладывается к его
запуску как артефакт `lr2-documentation`.

## Операции

- `add(a, b)` — сложение;
- `subtract(a, b)` — вычитание;
- `multiply(a, b)` — умножение;
- `divide(a, b)` — деление;
- `power(a, b)` — возведение `a` в степень `b`.

Например, `power(2, 3)` возвращает `8`, а `power(2, -3)` — `0.125`.

## Требования

Нужен Python 3. Выполнять команды следует из корневой папки репозитория.

## Запуск программы

```powershell
python LR2/main.py
```

## Запуск тестов

```powershell
python -m unittest discover -s LR2/tests -p "test_*.py"
```

При попытке деления на ноль функция `divide` возбуждает стандартное исключение
`ZeroDivisionError`. Такое же исключение возникает для `power(0, -1)`, потому
что ноль в отрицательной степени не определён. Оба случая покрыты тестами.
